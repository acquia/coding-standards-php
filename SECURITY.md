# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 4.x     | :white_check_mark: Supported |
| 3.x     | :white_check_mark: Supported via the `support/3` LTS branch |
| < 3.x   | :x: Not supported |

Security fixes for `3.x` should be prepared against `support/3`. Security fixes for the current major release line should be prepared against `main` and `develop` as appropriate.

## Reporting a Vulnerability

Send us an email at security@acquia.com; do not open a public issue. For more details, see [Acquia's responsible disclosure policy](https://www.acquia.com/why-acquia/industries/security#responsible-disclosure).
